# Code of Conduct

## Our Standard

We want this project to be welcoming to everyone. Contributors, maintainers, and users should treat each other with respect.

## Expected Behavior

- Be constructive in feedback and discussion
- Accept differing viewpoints gracefully
- Focus on what helps the project and its users

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Publishing others' private information without consent
- Any conduct that would be inappropriate in a professional setting

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and pull requests that violate this code. Repeated or serious violations may result in a ban from the project.

## Reporting

Report unacceptable behavior to support@webhooks.cc. All reports will be reviewed and handled confidentially.
